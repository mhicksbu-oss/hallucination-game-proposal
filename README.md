# Hallucination — Game Proposal Website

An evolving, research-backed proposal website for a game about unreliable perception.

## Preview locally

Open `index.html` in a browser, or serve the directory with any static file server.

## Structure

- `index.html` — proposal content and seven-section structure
- `styles.css` — responsive visual system and motion
- `script.js` — navigation, reading progress, and reveal behavior
- `RESEARCH.md` — verified sources, interpretations, gaps, and design decisions

The project is intentionally dependency-free so it can be published directly with GitHub Pages.
